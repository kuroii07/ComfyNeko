# 界面信息架构

## 全局导航

```text
首页总览
模型管理
资产管理
工作流库
提示词库
节点管理

底部固定：环境管理 / 偏好设置
```

主导航采用单层结构，中文名称统一为四个汉字。侧栏展开宽度固定，
不得由中文或英文文案撑宽；收起后仅保留图标和 Tooltip。

实例切换、当前环境、离线/运行状态和扫描进度放在标题栏或任务入口，
不占用主导航位置。扫描任务属于全局任务状态，健康检查归入环境管理，
回收站归入资产管理，诊断日志归入偏好设置。

Run 继续作为底层关联实体存在，但不设置独立导航页。模型、工作流、
提示词、参数、输入和输出关系在资产详情中展示；时间筛选与对比能力
归入资产管理页面。

## 资产详情页

采用三栏布局：左侧为搜索、收藏、目录和批次；中央为可缩放预览、视频播放或音频波形；右侧为详情检查器。

详情检查器按以下顺序展示：

1. 文件事实：位置、尺寸、大小、时长、创建/修改时间。
2. 生成资料：提示词、种子、采样器、模型与 LoRA。
3. 关系：所属 Run、输入、输出、工作流、项目和相似作品。
4. 操作：收藏、标签、复制参数、打开目录、导出可复现包、创建变体。

字段旁必须显示来源徽标，例如“来自 PNG metadata”“来自 Connector”“用户填写”。

## 模型页

- 默认卡片只显示封面、名称、类型、架构、标签、大小、健康状态和收藏。
- 详情侧栏显示触发词、推荐权重、示例 Run、重复候选、来源、备注和被引用关系。
- 目录树用于过滤，不等同于用户分类；用户分类、标签和收藏是独立维度。

## 工作流页

- 卡片需要封面、用途、标签、节点数、依赖模型/插件数、最后成功运行时间与健康徽标。
- 导入先打开“依赖体检”，再允许加载或创建副本。
- “分析”输出具体缺项和依据，不能只输出节点清单。

## 首页

首页不放推广内容。按优先级显示：正在进行的任务、最近 Run、待处理依赖问题、最近收藏和磁盘容量风险。
