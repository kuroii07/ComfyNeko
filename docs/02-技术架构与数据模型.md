# 技术架构与数据模型

## 推荐架构

```text
React UI (Tauri WebView)
        │ Tauri query commands + 800ms sequential polling
Rust Core ── shared SQLite pool / task queue / thumbnail cache / file watcher
        │ local connector protocol
ComfyUI Connector (Python custom node, optional)
        │
Bound ComfyUI instance / local folders / optional 127.0.0.1 API
```

桌面核心负责本地索引与安全文件操作，不能依赖 ComfyUI 必须运行。Connector 只在运行时补全队列事件、原始 prompt、执行状态和 Run manifest。

## 数据存储

- 数据库：`app_local_data_dir()/comfyneko.db`；Windows 当前对应 `%LOCALAPPDATA%\\com.kuroii.comfyneko\\comfyneko.db`。使用 SQLite WAL、外键、5 秒 busy timeout 和 SQLx 版本化迁移。
- 缓存：图片缩略图已落在 `app_local_data_dir()/cache/thumbnails/v1/`；Windows 当前对应 `%LOCALAPPDATA%\\com.kuroii.comfyneko\\cache\\thumbnails\\v1\\`。首版只生成 PNG、JPEG/JPG、WebP、BMP、TIFF/TIF 的 640px WebP，视频封面、GIF/AVIF、音频波形与其他可重建解析结果尚未实现。
- 用户原始文件：永不复制到数据库，不作为缓存清理目标。
- 配置/日志/备份：按环境 ID 分目录，任何配置写入使用原子替换和保留上一版本。

## 关键实体

- `Environment`：环境 ID、名称、ComfyUI 根目录、Python、端口、目录映射、健康状态、最近验证时间。
- `Asset`：稳定 ID、环境 ID、类型、规范化路径、大小、mtime、内容指纹、媒体属性、收藏与用户标签。
- `AssetScanTask`：环境 ID、根目录快照、任务状态、目录与资产计数、当前路径、取消请求、错误和开始/完成时间。
- `AssetScanDirectory`：任务内的目录级持久化队列，状态为 `pending`、`processing` 或 `done`；一个目录的资产、子目录、问题和检查点在同一事务提交。
- `AssetScanIssue`：记录不可读路径、根目录变化等扫描事实；存在可能漏扫的问题时禁止执行资产失效结算。
- `Model`：对应 Asset 的模型类型、SHA-256、架构、Civitai/本地来源、触发词、预览、备注与推荐参数。
- `Workflow`：源路径或库内快照、图结构摘要、依赖、封面、版本、收藏与分析结果。
- `PromptPreset`：提示词模块、变量、负面提示词、适配模型、版本和关联 Run。
- `Run`：环境、workflow snapshot、prompt snapshot、模型引用、参数、输入和输出资产，以及来源可信度。
- `ChangePlan`：计划动作、影响项、备份/撤销位置、确认时间、执行结果和审计日志。

## 稳定身份与元数据可信度

- 媒体初步身份使用规范化路径、大小和 mtime；确认去重或移动映射时使用内容指纹。
- 模型以完整 SHA-256 作为跨路径身份；哈希任务限速、可取消、可恢复。
- 字段来源必须写入 `source`：`connector`、`png_metadata`、`workflow_json`、`sidecar_txt`、`manual`、`remote_api`。
- `manual` 优先级最高；远端资料和推测结果不得覆盖用户资料。

## Connector 协议边界

- 仅监听本机、带一次性授权令牌；不将 ComfyUI API 暴露到局域网。
- 上报：环境版本、队列事件、prompt 快照、执行结果、输出文件和 Run manifest。
- 接收：读取当前工作流、请求在浏览器中打开指定 workflow、可选写入 manifest。
- Connector 不负责扫描磁盘、移动文件、下载模型或安装插件。

## 性能与可靠性

- 后台任务分为发现、解析、缩略图、哈希和远端元数据五类；前端实时显示进度与可取消状态。
- M2.2 已落地发现阶段：每个环境最多一个活动或可恢复任务；`queued/running/cancelling` 可停止为 `paused`，`paused/interrupted` 使用同一任务 ID 显式继续。
- 应用启动会把遗留的 `queued/running/cancelling` 归一化为 `interrupted`，把 `processing` 目录退回 `pending`，但不会自动恢复扫描。
- 只有目录队列完整结束、没有问题、未取消且环境根目录快照未变化时，才会把本轮未见资产标记为 `is_present = 0`；记录永不自动删除，重新发现时恢复同一资产 ID。
- 文件监听只作为增量提示；定期差异扫描才是正确性依据。
- 查询使用 FTS5、分页和缩略图懒加载；不得一次把所有元数据载入前端。
- 数据库迁移、缓存损坏、不可读文件和部分解析失败必须隔离，不能中断整个扫描任务。
- 缩略图命令只接收资产 ID。Rust 重新读取资产和环境事实，按 `input`/`output` 根目录分别执行规范化文件校验；缓存键包含资产 ID、源文件大小、修改时间和算法版本。写入使用同目录临时文件、同步和原子重命名，成功后只清理同资产的旧 WebP。
- Tauri Asset Protocol 仅启用 `$APPLOCALDATA/cache/thumbnails/**/*`，不会向 WebView 暴露已绑定的 ComfyUI 输入、输出或其他源目录。
