# 技术架构与数据模型

## 推荐架构

```text
React UI (Tauri WebView)
        │ Tauri commands/events
Rust Core ── SQLite / thumbnail cache / task queue / file watcher
        │ local connector protocol
ComfyUI Connector (Python custom node, optional)
        │
Bound ComfyUI instance / local folders / optional 127.0.0.1 API
```

桌面核心负责本地索引与安全文件操作，不能依赖 ComfyUI 必须运行。Connector 只在运行时补全队列事件、原始 prompt、执行状态和 Run manifest。

## 数据存储

- 数据库：`%LOCALAPPDATA%\\ComfyAssetHub\\asset-hub.db`，SQLite WAL + FTS5。
- 缓存：`%LOCALAPPDATA%\\ComfyAssetHub\\cache\\`，保存缩略图、视频封面、波形与可重建的解析结果。
- 用户原始文件：永不复制到数据库，不作为缓存清理目标。
- 配置/日志/备份：按环境 ID 分目录，任何配置写入使用原子替换和保留上一版本。

## 关键实体

- `Environment`：环境 ID、名称、ComfyUI 根目录、Python、端口、目录映射、健康状态、最近验证时间。
- `Asset`：稳定 ID、环境 ID、类型、规范化路径、大小、mtime、内容指纹、媒体属性、收藏与用户标签。
- `Model`：对应 Asset 的模型类型、SHA-256、架构、Civitai/本地来源、触发词、预览、备注与推荐参数。
- `Workflow`：源路径或库内快照、图结构摘要、依赖、封面、版本、收藏与分析结果。
- `PromptPreset`：提示词模块、变量、负面提示词、适配模型、版本和关联 Run。
- `Run`：环境、workflow snapshot、prompt snapshot、模型引用、参数、输入和输出资产，以及来源可信度。
- `ChangePlan`：计划动作、影响项、备份/撤销位置、确认时间、执行结果和审计日志。

## 稳定身份与元数据可信度

- 媒体初步身份使用规范化路径、大小和 mtime；确认去重或移动映射时使用内容指纹。
- 模型以完整 SHA-256 作为跨路径身份；哈希任务限速、可取消、可恢复。
- 字段来源必须写入 `source`：`connector`、`png_metadata`、`workflow_json`、`sidecar_txt`、`manual`、`remote_api`。
- `manual` 优先级最高；远端资料和推测结果不得覆盖用户资料。

## Connector 协议边界

- 仅监听本机、带一次性授权令牌；不将 ComfyUI API 暴露到局域网。
- 上报：环境版本、队列事件、prompt 快照、执行结果、输出文件和 Run manifest。
- 接收：读取当前工作流、请求在浏览器中打开指定 workflow、可选写入 manifest。
- Connector 不负责扫描磁盘、移动文件、下载模型或安装插件。

## 性能与可靠性

- 后台任务分为发现、解析、缩略图、哈希和远端元数据五类；前端实时显示进度与可取消状态。
- 文件监听只作为增量提示；定期差异扫描才是正确性依据。
- 查询使用 FTS5、分页和缩略图懒加载；不得一次把所有元数据载入前端。
- 数据库迁移、缓存损坏、不可读文件和部分解析失败必须隔离，不能中断整个扫描任务。
