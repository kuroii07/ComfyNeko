# 环境绑定与安全设计

## 首次启动流程

1. 自动发现候选环境：常见目录、最近打开路径、运行中 ComfyUI 进程和用户手动浏览。
2. 用户选择候选根目录，或输入路径。
3. 自动发现 Python：优先读取该环境的 `.venv\\Scripts\\python.exe`、启动脚本和进程命令行；用户可覆盖。
4. 解析 `models`、`custom_nodes`、`input`、`output`、`user`、`workflows` 和外部模型路径。
5. 执行只读预检，显示通过、警告、阻塞问题及原始证据。
6. 用户命名环境并确认保存，之后才允许扫描。

## 必须通过的预检

- ComfyUI 根目录存在，并能找到用于识别的主程序/配置特征。
- Python 文件存在、可执行，并报告版本、解释器路径和基础导入结果。
- 每个已配置资产目录可读取；不存在路径只产生可解释警告，不能自动创建。
- 如设置端口且目标正在运行，才探测本机 API；API 不通不妨碍离线资产库。
- 解析目录与 extra model paths 后，报告同一目录被多次映射、路径逃逸和权限不足。


## 写操作安全门槛

- 扫描、解析、缩略图和本地数据库写入无需修改绑定环境文件。
- 删除、移动、实体重命名和工作流修改只能由 `ChangePlan` 执行。
- `ChangePlan` 必须列出原路径、目标路径、冲突策略、引用数、备份位置和撤销方案。
- 默认删除到应用回收站；如果回收站不可用则中止，而非永久删除。
- 环境绑定失败时禁止修复、移动和批处理写入，但允许用户查看诊断报告。

## 不可靠数据的处理

- PNG 的 workflow/prompt metadata 可信度高于同名 `.txt`，但仍不代表视频或音频的完整生成过程。
- 无 Connector 的视频和音频一律标记为“媒体信息不完整”，除非同目录或数据库中找到经过校验的 manifest。
- 远端 Civitai 元数据、相似文件名匹配和模型医生建议均需要人工确认。
