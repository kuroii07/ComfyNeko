# ComfyNeko 产品需求与范围

## 产品定位

ComfyUI 资产中枢不是模型下载器，也不是单纯 output 图库。它是一个本地创作资产系统：用户能从任意模型、提示词、输入素材、输出图片/视频/音频或工作流，找到其关联关系，并在条件允许时复现生成。

## 核心用户问题

1. 多套 ComfyUI、不同 Python 环境和外接模型目录难以辨认，误操作风险高。
2. 模型数量大，文件名混乱，难以知道模型用途、来源、触发词和是否重复。
3. `input`、`output`、视频和音频分散；作品与工作流、模型、提示词失去关联。
4. 收藏的提示词和工作流无法按项目、模型和成功作品复用。
5. 导入工作流时无法可靠说明缺的是什么，以及修复会影响哪里。

## 北极星能力：Run

一个 Run 表示一次可追溯的生成尝试，至少关联：环境、工作流快照、提示词、模型身份、输入资产、参数和输出资产。新产生的媒体优先通过 Connector 写入 Run manifest；从旧目录扫描出的媒体可创建“已发现 Run”，并标注 metadata 来源和不完整项。

## MVP 范围

- 多环境档案：发现、绑定、预检、切换、重新验证。
- 只读扫描：模型、`input`、`output` 和用户指定的白名单目录。
- 图片、视频、音频统一资产库：预览、搜索、标签、收藏、详情侧栏。
- 模型资料：路径、类型、大小、哈希、封面、触发词、备注、标签、来源和重复候选。
- 提示词与工作流收藏：版本、封面、标签、依赖清单、导入前体检。
- Run 记录：读取 PNG metadata / workflow，或读取 Connector sidecar manifest；支持打开原工作流和复制参数。
- 非破坏性操作：扫描、虚拟分类、收藏、标签和缓存管理。

## 非 MVP 范围

- 自动下载模型、云账号、团队协作、插件市场、远程执行、自动安装依赖。
- 默认实体重命名、自动替换模型、自动改写工作流。
- 以 AI 推测为依据的模型或提示词“精确复原”。

## 成功标准

- 用户在三步内从一份作品打开关联提示词、模型清单和工作流。
- 用户能同时绑定至少两套 ComfyUI，且索引不会混淆目录归属。
- 首次扫描不阻塞界面；取消后可恢复；重新扫描只处理变更项。
- 所有写操作在执行前显示影响文件数、目标路径和撤销策略。

## 参考产品的采纳原则

- 采用 TE 媒体浏览器的三栏详情、对比模式、批量浏览与 workflow 导出体验。
- 采用 ComfyNexus 的独立桌面壳、多环境入口、资产目录和模型资料卡。
- 不复制其完整菜单堆叠、未确认的自动修复，或以单个 JSON 文件承载大规模图库索引的实现。
