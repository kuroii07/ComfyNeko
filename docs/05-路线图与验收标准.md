# 路线图与验收标准

## Phase 0：环境基础（已完成）

交付环境绑定向导、环境档案、本地预检、诊断报告和只读路径白名单。

验收：同一应用可保存两个环境；错误 Python、不可读目录、非 ComfyUI 根目录和离线 API 都给出具体诊断，不修改任何外部文件。

完成证据：命令服务文件数据库重启读回测试覆盖同一数据库保存两个环境并重新连接读取；真实 ComfyUI/Python 只读 smoke 覆盖有效环境、错误 Python 和离线 API，绑定根目录递归快照前后一致；环境页已收敛为单列设置界面，支持根目录自动识别、全部路径手动编辑、原生文件/目录选择和资源管理器打开，且自动识别不会覆盖手动值；前端、Rust、Clippy 与 Tauri 构建通过。用户可直接运行桌面程序继续手动视觉与交互验收。

## 发布门槛

- Windows 10/11 真实机器验收，至少覆盖独立 Python 与 `.venv` 两类环境。
- 不同模型目录、外接盘路径、长路径、中文路径、缺权限目录和 API 未启动情形均有测试。
- 全部写操作有手工回归；关键数据模型、路径检查、迁移和解析器具备自动测试。
- 不因扫描、缩略图失败、远端 API 失败或单个坏媒体文件崩溃。
