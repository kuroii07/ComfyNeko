## 发布门槛

- Windows 10/11 真实机器验收，至少覆盖独立 Python 与 `.venv` 两类环境。
- 不同模型目录、外接盘路径、长路径、中文路径、缺权限目录和 API 未启动情形均有测试。
- 全部写操作有手工回归；关键数据模型、路径检查、迁移和解析器具备自动测试。
- 不因扫描、缩略图失败、远端 API 失败或单个坏媒体文件崩溃。
