# 路线图与验收标准

## Phase 0：环境基础

交付环境绑定向导、环境档案、本地预检、诊断报告和只读路径白名单。

验收：同一应用可保存两个环境；错误 Python、不可读目录、非 ComfyUI 根目录和离线 API 都给出具体诊断，不修改任何外部文件。

## Phase 1：资产库 MVP

交付增量扫描、SQLite 索引、图片/视频/音频预览、收藏、标签、全文搜索、模型基本资料和缓存管理。

验收：扫描可取消恢复；重复扫描不产生重复资产；不可读/损坏文件只记录错误；至少能按媒体类型、目录、模型和收藏过滤。

## Phase 2：工作流与 Run

交付工作流库、依赖解析、PNG metadata 解析、Connector manifest、Run 详情和恢复入口。

验收：一张带 workflow metadata 的图片可链接到 Run；一个 Connector 记录的图片/视频/音频可展示完整来源；缺字段明确标记而非伪造。

## Phase 3：安全变更与维护

交付 ChangePlan、回收站、模型重复确认、虚拟命名、导入体检和工作流修复建议。

验收：每个写操作都能在执行前显示计划；取消不改变源文件；成功后能在审计日志看到结果；可撤销动作可恢复。

## Phase 4：高级能力

包括多实例实时状态、对比实验、相似媒体、项目打包/迁移、可选远程元数据和受限的插件维护。

## 发布门槛

- Windows 10/11 真实机器验收，至少覆盖独立 Python 与 `.venv` 两类环境。
- 不同模型目录、外接盘路径、长路径、中文路径、缺权限目录和 API 未启动情形均有测试。
- 全部写操作有手工回归；关键数据模型、路径检查、迁移和解析器具备自动测试。
- 不因扫描、缩略图失败、远端 API 失败或单个坏媒体文件崩溃。
