# ComfyNeko

> 守住灵感，找回每一次生成。

ComfyNeko 是本地优先的 Windows 桌面软件：连接一套或多套 ComfyUI，统一管理模型、输入素材、输出媒体、提示词、工作流与可复现的生成记录（Run）。

## 当前阶段

- 阶段：~~M1 环境绑定与 Phase 0 环境基础~~ 已完成；环境领域、只读预检、受限运行时探测、SQLite 环境档案、Tauri IPC、四分区环境设置页和已保存环境列表均已落地。
- 环境路径：填写 ComfyUI 根目录后可自动识别 Python、模型、输入、输出、工作流与自定义节点目录；所有路径均可手动编辑，也可通过原生窗口选择并在资源管理器中打开。自动识别不会覆盖用户已经手动修改的值。
- 应用导航：已建立固定宽度的四字单层功能栏，包含首页总览、模型管理、资产管理、工作流库、提示词库和节点管理；环境管理与偏好设置固定在侧栏底部。各入口保持独立职责：“资产管理”只负责图片、视频和音频，模型、节点插件与工作流分别由“模型管理”“节点管理”“工作流库”承载。
- 资产扫描：~~Phase 1 的 M2.2 后台只读扫描任务~~ 已完成。扫描只读取已保存环境中的模型、输入、输出和工作流目录，支持持久化目录队列、取消、同任务恢复、重启后显式恢复、问题记录和保守失效标记；不会扫描 `custom_nodes`，也不会创建、修改、移动、重命名或删除 ComfyUI 文件。
- 资产查询：~~M2.3a 后端分页与基础筛选接口~~ 已完成。查询只读取 ComfyNeko SQLite，按环境隔离，支持资产类型、根目录类别、目录及在场/失效状态组合筛选；使用稳定路径排序、1 起始页码、默认每页 50 条且最多 100 条，并返回列表所需的名称、目录、大小、时间和状态字段。通用索引仍可保存模型与工作流记录，但资产库调用固定使用 `media_only=true`，只返回 `image`、`video`、`audio`；省略或关闭该参数仅保留给独立功能页与内部查询。
- 当前目标：继续 M2.3b，完成媒体资产列表、筛选、分页和受控缓存目录；模型的 Checkpoint、Diffusion Model、LoRA、VAE、Text Encoder 等子分类在“模型管理”独立细分，工作流和节点插件也不进入资产库。在明确批准写操作前，继续保持已绑定 ComfyUI 目录只读。
- 环境设置：页首已按 ComfyNexus 的单层结构与排版收敛为 sticky 布局，左侧显示标题、真实状态和当前环境，中间放置四个页签，右侧保留检查与“保存档案”；已移除重复的大标题、帮助按钮和伪控制台眉题。已保存环境改为紧凑的单行切换栏，支持鼠标、新建档案、方向键与 Home/End 快速切换；切换档案、重新开始新建档案或离开环境页前会保护未保存的基础字段与会话草案，保存刷新后编辑器会同步持久化档案。通用设置的说明列、配置列和字段行密度也已收紧，长中英文、Windows 路径和 320/240px 窄窗口中的路径操作不会被静默裁切。加速、模型分类映射和环境变量属于当前会话草案，页首会明确显示“会话草案”或“草案有误”；“保存档案”只持久化基础环境档案，不会误导为已保存这些高级草案。模型路径继续支持原生选择、打开和只读自动发现；加速参数与启动环境变量未来只会以可预览、备份和撤销的 ChangePlan 形式开放。
- 默认原则：只读、可预览、可撤销；不修改已绑定 ComfyUI 的任何配置，除非用户明确确认。
