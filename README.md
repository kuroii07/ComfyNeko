# ComfyNeko

> 守住灵感，找回每一次生成。

ComfyNeko 是本地优先的 Windows 桌面软件：连接一套或多套 ComfyUI，统一管理模型、输入素材、输出媒体、提示词、工作流与可复现的生成记录（Run）。
